# Veil

tvOS 风格的 Android TV / 盒子桌面（launcher），干净、轻量、纯原生 View 实现。

**基于 [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv)（MIT License）二次开发** —— 感谢原作者的出色底子，本项目在其基础上做了大量修复、功能增强与界面重制。

### v2.1.3：液态玻璃 UI + 航拍视频「下载再播」+ 界面全中文

让桌面视觉接近 iOS / Apple TV 的「液态玻璃」质感，并彻底修好航拍视频在国产盒子上的播放：

- **玻璃材质重制**：顶栏药丸按钮、设置面板、信源/卡片弹窗、应用磁贴、对话框全部换成**半透明玻璃材质**——顶部一道高光（模拟光线打在玻璃上）、更细更亮的描边、更圆的圆角，告别原来那条「扁平深色渐变」。
- **真·背景模糊（Android 12+ / API 31+）**：设置面板开启后，面板背后的实时桌面会被**真实模糊**，呈现 Apple 那种磨砂玻璃；旧机型没有系统级模糊，自动回落到「半透明玻璃 + 高光」的拟态质感。
- **开关可控**：「设置 → 系统 → 液态玻璃」一行可开/关（默认开）；关掉则回到普通面板。
- **航拍视频改为「下载再播」**：沿用 Aerial 应用的架构——视频先缓存到本地（断点续传，单条约 66–450 MB，实测约 4 MB/s）再播放，播完自动预取下一条，缓存池 LRU 上限 600 MB / 4 条。彻底解决部分国产盒子（如斐讯 T1，Android 7）上苹果 CDN 流式播放失败的问题：证书链验不过导致 MediaPlayer 流式必死，本地文件播放则畅通。首条下载完成前桌面显示静态壁纸，不会黑屏。
- **修复壁纸黑屏**：壁纸图层曾被视频 SurfaceView 的透明挖孔区盖住（部分盒子上空 SurfaceView 合成为不透明黑色层），导致桌面常年全黑——已修正图层顺序，视频空闲/失败时自动收纳表面。
- **界面全中文**：设置里守护/锁定/液态玻璃/控制中心等英文文案全部汉化，并补齐 38 条缺失翻译；英文底版回归英文，中文统一收在 `values-zh-rCN`。
- 版本号 213 → 214，版本名 2.1.3；full / lite 双包构建通过，已在斐讯 T1（Android 7.1.2）实机验证。

### v2.1.1：修复 Android 6 盒子点击桌面图标无反应

这一版只修一个但很致命的问题，改动在 Android 6（API 23）电视盒子上验证：

- **桌面图标点不动**：旧版首次点击应用图标会请求屏幕录制授权（MediaProjection 弹窗），
  而部分 Android 6 遥控器环境该弹窗根本不弹出，授权回调永远不触发，应用也就起不来。
  本版把「内容预览」默认改为关闭，并且在 Android 6 及以下**直接启动应用、跳过授权流程**，
  桌面图标点击立即生效。Android 7+ 设备仍可在设置里手动开启内容预览。

### v2.1.2：桌面航拍视频「真播」+ 信源一键直达

这一版让桌面像 Apple TV 的 Aerial 一样**直接播放会动的航拍视频**，并把视频源从设置里挪到桌面：

- **航拍视频放进「壁纸来源」（不在信源里）**：在「设置 → 壁纸 → 航拍图源」里新增了 **「航拍视频（动态背景，在线真播）」** 一项。
  选它之后，桌面背景就改为**在线流式播放 Apple 的 2K 航拍视频**（复用 Aerial 屏保同一套播放器），画面会动，和 Apple TV 的 Aerial 一样。
  信源（HDMI 接口选择器）**保持原样**，只列 HDMI 1/2、AV、Live TV 这些真实视频接入源，不混入航拍视频。
  视频网络或解码失败会自动退回静态航拍图，桌面不会黑屏、不会卡死，并会隔一段时间自动重试。
  > 说明：视频走 Apple 服务器在线流式播放，会占用网络流量（与 Aerial 屏保一致）；若你更想要
  > 完全离线的本地视频背景，需要把视频文件打进安装包，体积会明显变大——这版先按「和 Aerial 一样」的在线方案做。
- **桌面守护（看门狗）保活**：借鉴 at4k / tigris / cleanyourtv 的思路，新增两层保活，确保父母的电视始终停留在本桌面：
  1. **隐形看门狗（无障碍服务 `LauncherGuardService`）**：一旦别的 HOME / 桌面应用（盒子原桌面、另一个 launcher）抢占屏幕，就自动把本桌面拉回来。
     只拦**竞争桌面**，打开 Netflix、设置、普通 App 完全不受影响，电视照常好用。默认开启，可在「设置 → 系统」里关掉。
  2. **开机自启（`BootReceiver`）**：开机或本应用更新后，自动把桌面拉起来，不用任何人按遥控器。同样由上面的开关统一控制。
  > 无障碍服务需要你在系统「辅助功能」里手动允许一次（设置里有对应入口和提示）；这正是 at4k 那种"隐形、无通知、系统不杀"的保活方式的代价。
  > 想要最稳，可再用一条 adb 命令把盒子原桌面停用（`pm disable-user 原桌面包名`），让本桌面成为唯一 HOME。
- 版本号 211 → 212，版本名 2.1.1 → 2.1.2；两个安装包（full / lite）均已重新构建通过。

### v2.1.0：壁纸图库预览、图标自由换位、长按卸载应用

这一版新增三项实用功能，全部改动均在 Android 7.1.2 测试设备实测通过：

- **壁纸图库预览 + 上一张/下一张**：设置面板里，航拍 / 必应 / 360 三个壁纸源各多一行
  「图库预览」，点进去是全屏画廊 —— 大图实时预览 + 缩略图胶片条 + 「上一张 / 下一张 /
  设为壁纸 / 关闭」四个按钮。当前正在当壁纸的那一张在胶片条上打白点标记。
  「上一张 / 下一张」是**直接换壁纸**（不是只预览），桌面立刻跟着变。
  4K 图满尺寸解码有 33 MB，小内存盒子扛不住，所以预览走采样解码。
- **图标移动换位置**：长按应用图标 → 「移动到其他位置」→ 图标变半透明（拿起来了），
  方向键走到想要的位置，OK 放下，返回键放回原处。位置写进本地设置，**重启后还在**；
  手动排好的顺序之后，新装的 App 不会插队进来。
- **长按删除应用**：长按菜单最末一项「删除应用」，先弹 Veil 自己的确认框，确认后调起
  系统卸载器，系统那边再确认一次 —— 双保险，不会误删。

### v2.0.1：老安卓盒子上的壁纸源修复（真机实测 Android 7.1.2）

这一版修的是「只有必应能用，其他图源全都连不上」的问题，全部改动均在 Android 7.1.2 测试设备实测通过：

- **统一 HTTP 客户端 + TLS 降级**：安卓 7 的系统证书库太老（2019 年前的根证书），
  现代 CDN 的证书链一律握手失败（`Trust anchor for certification path not found`）。
  现在先用系统信任，握手失败再放宽校验重试一次 —— 必应 / 360 图床 / Apple 航拍 / 天气
  全部恢复 200。
- **360 图库「IP Forbidden」的真相**：它不是网络封锁，而是**请求窗口越界**。实测该接口
  只开放每个分类的**前 1000 条**，且 `count` 不能超过 99；越界时服务端用
  `errno 1105 / Proxy Warning - IP Forbidden` 回答（这句话极具误导性）。现在请求窗口
  按合法范围取，并用**滚动游标**而不是随机起点，连点扩充也能持续拿到新图。
- **航拍扩充静默失败**：4K 视频头（48–80 MB）整块读进内存，在小内存盒子上触发
  `OutOfMemoryError` —— 而它是 `Error`，逃过了所有 `catch (Exception)`，于是扩充报告显示
  「0 张、无错误」。现在改为**流式落盘**、捕获 `Throwable`，并在 1080p 屏上自动跳过
  4K（HEVC 软解）路线。
- **必应多市场图库提为通用兜底**（`BingStock`）：360 / 航拍任一路径失效时自动用必应
  补足，**扩充永远有图**，不再以「连接不上服务器」收场。
- **网络自检工具**：设置面板新增「网络自检」，逐源打印 DNS / TCP / HTTP / 响应首段；
  也可 `adb shell am broadcast -a com.veil.launcher.NETCHECK` 触发。

## 特性

- **tvOS 风界面**：毛玻璃 Dock 与顶栏（壁纸实时取样模糊）、焦点缩放动画、三级设置菜单
- **航拍屏保与壁纸**：Apple TV 航拍视频流播放（114 段）、航拍静图轮换、一键扩充图库、4K 分辨率档
- **必应每日壁纸**：每日一图，4K 源，库存轮换
- **扫码上传壁纸**：电视显示二维码，手机扫码打开本地网页即可传图（内置 HTTP 服务器 + 零依赖 QR 编码器，无需安装任何 App）
- **桌面锁定**：无障碍服务拦截其他桌面，防家人误改默认桌面
- **控制中心**：本机 adb 环回（127.0.0.1:5555）实现设备信息 / 重启 / 关机
- **天气时钟**：Open-Meteo 免费源，中文城市搜索
- **应用管理**：文件夹 + 4 位密码锁、图标自定义与圆角、Dock 数量调节、隐藏应用、**图标自由换位**、**长按卸载应用**
- **壁纸图库预览**：三个壁纸源各带一个全屏画廊，大图预览 + 胶片条 + 上一张/下一张（即时换壁纸）
- **屏保**：航拍/必应壁纸混池，交叉淡化 + 缩放防烧屏
- 最低 **Android 6.0**（minSdk 23），无第三方功能库

## 构建

```
./gradlew assembleFullRelease assembleLiteRelease
```

产物：`app/build/outputs/apk/full/release/Veil-TV-full-release.apk`、
`app/build/outputs/apk/lite/release/Veil-TV-lite-release.apk`。

需要 JDK 17 与 Android SDK（compileSdk 34）。
